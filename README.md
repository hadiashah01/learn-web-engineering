## Overview

This repository documents eight Web Engineering sessions, progressing from web fundamentals and HTML to CSS, browser developer tools, accessibility, CSS architecture, and Flexbox-based layouts.

Each day contains its own documentation and, where applicable, practical implementations, screenshots, recordings, assignments, and demo files.

## Practical Implementations

The repository includes hands-on frontend implementations built alongside the documented concepts.

### Box Model & Display Property

Exploration of the CSS box model, display modes, nested elements, selectors, and BEM-style modifiers.

### CSS Units & Layout

Implementation covering relative and absolute CSS units, `calc()`, Flexbox, nested layouts, and BEM naming.

### Cards Layout with BEM

Reusable card structures using BEM naming, Flexbox wrapping, spacing, and component-level styling.

### Mentorship Dashboard

A dashboard-style layout featuring metric cards, detail cards, nested Flexbox containers, and reusable layout utilities.

### Multi-section Flexbox Layout

A multi-section interface combining a header, sidebar navigation, content sections, and nested Flexbox layouts.

## Technologies & Tools

- **HTML5** — Semantic markup, forms, and media elements
- **CSS3** — Styling, typography, layout, and animations
- **CSS Flexbox** — Flexible layouts, alignment, and responsive arrangements
- **BEM** — Block-Element-Modifier CSS methodology
- **Chrome DevTools** — Inspection, debugging, accessibility, and layout analysis
- **Visual Studio Code** — Development environment
- **Emmet** — HTML and CSS abbreviations and shortcuts
