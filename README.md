# Web Engineering

A day-wise collection of Web Engineering documentation, browser experiments, and practical frontend implementations covering HTML, CSS, Chrome DevTools, accessibility, BEM, Emmet, and Flexbox.

## Overview

This repository documents eight Web Engineering sessions, progressing from web fundamentals and HTML to CSS, browser developer tools, accessibility, CSS architecture, and Flexbox-based layouts.

Each day contains its own documentation and, where applicable, practical implementations, screenshots, recordings, and assignment material.


## Day-wise Lessons

| Day | Focus | Key Topics | Practical Work |
|-----|-------|-----------|-----------------|
| [Day 01](day-01/README.md) | Internet & Web Fundamentals | Internet, Web, HTTP, CORS, Authentication & Authorization | — |
| [Day 02](day-02/README.md) | HTML Essentials | HyperText, Markup, DTD, Attributes, Emmet | — |
| [Day 03](day-03/README.md) | CSS Basics | CSS Fundamentals, Chrome DevTools, Specificity, Display | — |
| [Day 04](day-04/README.md) | CSS Box Model | Box Model, Selectors, DevTools | Box Model & Display Property |

| [Day 06](day-06/README.md) | Accessibility | Semantic vs Presentational Formatting, DevTools Accessibility | Cards Layout with BEM |
| [Day 07](day-07/README.md) | Flexbox Layouts | Flexbox & Card Components | Mentorship Dashboard |
| [Day 08](day-08/README.md) | Flexbox Advanced | Flexbox, Navigation Bars, Headers, `flex-wrap`, `flex-grow` | Multi-section Flexbox Layout |

## Practical Implementations

The repository includes hands-on frontend implementations built alongside the documented concepts:

- **Box Model & Display Property** — CSS Box Model, display modes, nested elements, and BEM-style modifiers.
- **CSS Units & Layout** — CSS units, `calc()`, Flexbox, nested layouts, and BEM.
- **Cards Layout with BEM** — Reusable card structure, modifiers, Flexbox wrapping, and spacing.
- **Mentorship Dashboard** — Metric cards, detail cards, nested Flexbox containers, and layout utilities.
- **Multi-section Flexbox Layout** — Header, sidebar navigation, content sections, and nested Flexbox layouts.

## Technologies & Tools

- **HTML5** — Semantic markup, forms, media elements
- **CSS3** — Layout, typography, animations
- **CSS Flexbox** — Flexible layouts and alignment
- **BEM** — Block-Element-Modifier CSS methodology
- **Chrome DevTools** — Inspection, debugging, and optimization
- **Visual Studio Code** — Code editor
- **Emmet** — HTML/CSS abbreviations and shortcuts
